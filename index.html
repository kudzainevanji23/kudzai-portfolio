Projects

Behaviour verification for Matter hubs

2024–2026 · An LSTM-autoencoder security layer for smart-home hubs

Device event logs→LSTM autoencoder learns normal patterns→Reconstruction error per sequence→Deviation score→Policy engine: Allow, Confirm, MFA, Block

Problem

Matter protects smart homes with authentication and ACL permissions, but an authenticated device or account can still behave abnormally. Permissions alone cannot tell whether an action fits the user’s normal pattern.

Approach

Learn what normal looks like from device event logs, score how far new behaviour deviates, and respond proportionally instead of a binary allow or deny.

Key contributions

  • A behaviour-aware layer that complements Matter’s authentication and ACL model.
  • A reconstruction-error to deviation-score mapping (Behavioural Intent Verification).
  • A four-level policy engine balancing security and convenience.
  • Python implementation (TensorFlow / PyTorch), deployed with Docker on Linux.

Cross-layer caching for HPC

2025–2026 · Experimental evaluation of Alluxio and Ceph tiering under HACC-IO

Application / HACC-IO workload⇅Alluxio cache tier (via FUSE)⇅Ceph distributed storage tier

Problem

HPC workloads put heavy, mixed read and write pressure on storage. Where data lives across cache and storage tiers strongly affects both read efficiency and write throughput.

Approach

Evaluate Alluxio (cache) and Ceph (storage) tiering with the HACC-IO workload, and test whether a hybrid design with intelligent data placement can optimise both.

Key contributions

  • Experimental evaluation of Alluxio and Ceph tiering on HACC-IO workloads.
  • Showed a hybrid cross-layer design with intelligent placement improves both read efficiency and write throughput.
  • Linux-based experiment environment using FUSE.
